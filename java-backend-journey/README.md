# Java Backend Developer Journey (24 Weeks)

A practical, GitHub-tracked learning plan for moving from Application/Production Support into Java Backend Development.

**Start date:** 22 November 2026  
**Duration:** 24 weeks  
**Daily commitment:** 2–3 hours (default plan: 150 minutes)  
**Primary stack:** Java, Spring Boot, SQL, PostgreSQL/Oracle, Kafka, Redis, Docker, Kubernetes

## How to use this repository

1. Work through `ROADMAP.md` in order.
2. Use `DAILY-TRACKER.md` to tick off daily tasks. Commit the file after each study session.
3. Tick a weekly milestone in `WEEKLY-TRACKER.md` only after completing its deliverable.
4. Copy `templates/DAILY-LOG.md` into `daily-logs/` for each study day.
5. Record Sunday reflections in `weekly-reviews/`.
6. Put actual code for exercises and projects in the relevant folders. A checked box is not a substitute for code.

## Daily routine (150 minutes)

| Activity | Time | Rule |
|---|---:|---|
| Learn one concept | 30 min | Prefer official docs and notes |
| Hands-on coding | 60 min | Write from a blank file; don't copy |
| DSA | 30 min | One problem, explain complexity |
| Project/revision | 30 min | Build, test, document, commit |

**Sunday:** weekly revision, five questions without help, finish pending work, review Git history, plan next week. If work is busy, do a 90-minute minimum session rather than abandoning the habit.

## Rules

- Do not commit employer code, production data, credentials, screenshots, internal hostnames, or confidential configuration.
- Use synthetic data for the banking transaction monitoring project.
- Do not move to the next topic only because you watched a tutorial. Demonstrate it in code.
- Use Java 8 concepts as a foundation, but learn Java 17+ for modern Spring Boot projects.
- Keep React secondary; the target role is Java Backend Developer.
